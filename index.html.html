MAIN WORKFLOW — follow this order for the new LRFD method

  1. Find the factored actions: calculate the governing load combination and obtain Mu (and Vu for shear).
  2. Analyze the section: establish strain compatibility using εcu = 0.003, determine c and a = β₁c, and check whether the tension steel yields.
  3. Calculate nominal strength: use force equilibrium and the internal lever arm to calculate Mn.
  4. Find φ: use the tensile strain and the applicable strength-reduction provisions.
  5. Check capacity: verify φMn ≥ Mu, then separately check minimum reinforcement, spacing/detailing, shear, and serviceability as required.
  6. Use the lecture presets: compare intermediate values—not just the final answer—with your professor's examples.

Part 2: Strength design (LRFD, ultimate strength method)

The rule: required strength ≤ available strength. ASD: Ra ≤ Rn/Ω, service loads against one safety factor on the resistance. LRFD: Ru ≤ φRn. The loads are multiplied by load factors (loads vary, the analysis is approximate, failure has consequences) and the nominal strength is reduced by φ (material strength, dimensions, workmanship and the type of failure all vary). In RC the beam is checked at the failure state: concrete strain 0.003, a rectangular stress block, steel at fy or Es·εs. Deflection and cracking are checked separately at service load.

Beam analysis by strength: is it under or over-reinforced, and what is φMn?

Where the equations come from

(1) Strain triangle with εc = 0.003: c/d = 0.003/(0.003 + εs). (2) The curved concrete stress is replaced by a rectangle of 0.85f′c over a = β₁c, which gives the same force and the same centroid. Steel: fs = Es·εs up to fy. (3) T = C: As·fs = 0.85f′c·a·b, so a = As·fy/(0.85f′c·b). (4) Moments about C or T: Mn = As·fy(d − a/2). (5) With a = ρ·fy·d/(0.85f′c): Mn = ρbd²fy(1 − 0.59ρ·fy/f′c), because 0.5/0.85 = 0.59. (6) Over-reinforced: fs = 600(β₁d − a)/a from the strain triangle, put into As·fs = 0.85f′c·a·b, which is a quadratic in a. (7) εt = 0.003(dt − c)/c, then φ from the table. For balance, use εy = fy/Es; the lecture separately permits εty = 0.002 for Grade 400–420 MPa when setting the φ transition and ρmax. (8) φMn ≥ Mu.

Mn against ρ: why the design uses the smaller root

Uses b, d, f′c, fy and dt from the analysis card. Mn grows with ρ, flattens, then falls once the steel stops yielding, so one moment can come from two ρ values. The larger root is over-reinforced and wasteful, so only the smaller root is used. φMn drops in the transition zone.

Notes on the lecture

(1) Lecture p.13 prints "if ρ < ρmax then compression control". The logic is the reverse: ρ ≤ ρmax gives εt ≥ 0.005 (tension-controlled, φ = 0.9), and ρ above it is the transition or compression zone. (2) The p.5 solution uses 0.5L in 1.2D + 1.6S + 0.5L (older ASCE form), while the Table 5.3.1 on p.4 has 1.0L. This page uses the table, and the controlling result (214.4 kN) is the same. (3) For fy between 400 and 420 MPa the lecture takes εty = 0.002 (εt = 0.005); this page does the same, and uses fy/Es for other grades (p.16 uses 345/200000). (4) The over-reinforced case here is solved exactly with the quadratic, as on p.19, and the section is then given φ from its εt.

RC equations, one by one

Where they come from: (1) plane sections stay plane, so εc/εs = kd/(d − kd). (2) Hooke's law, fs = Es·εs and fc = Ec·εc, so fs = n·fc·(d − kd)/kd. (3) Concrete in tension is ignored, so force balance gives C = T, that is ½·fc·b·kd = As·fs. (4) The same balance as moments about the N.A.: b·(kd)²/2 = n·As·(d − kd), which gives k. (5) Moment = C·jd = T·jd. The values below use the beam in the RC tab.
